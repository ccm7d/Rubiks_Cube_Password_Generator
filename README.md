# Rubik Cube Password Generator

A Python project that generates passwords using Rubik's Cube movements.

## Files

- `Password_Generator.py` - Main program for generating passwords.
- `Functions.py` - Contains Rubik's Cube logic and password generation functions.
- `Rubiks_Cube.py` - Interactive Rubik's Cube simulator.

## Requirements

- Python 3.x
- NumPy

## Installation

pip install -r requirements.txt

## Run

python Password_Generator.py
